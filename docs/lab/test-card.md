# Test card (copy to `data/private/lab/<you>/<date>-<slug>/card.md`)

Fill every line before running anything. One page.

- **Question:** one sentence, answerable yes / no / cannot tell.
- **Why it matters:** what we would do differently for each answer.
- **Rule set:** which `lab.views` entry (or a new one, with its conditions).
- **Method:** what is computed, with which existing module or model.
- **Known-answer check:** the books or authors whose answer is known, and the hit rate the
  method must reach on them before the real run counts.
- **What counts as yes / as no:** the number and the bar, written now.
- **Decoys:** what should *not* come out on top if the method works (dead authors, later books).
- **Lessons checked:** the numbers from `docs/lab/lessons.md` that apply, and how each is handled.
- **Cost:** my time, machine time, rented GPU (zero unless the owner has approved an amount).
- **Outputs:** where they go (text-quoting: `data/private/lab/...`; numbers only: may be public).

After the run, add: **Result** (the numbers, and the known-answer hit rate beside them),
**What it does not show**, **Next**.
